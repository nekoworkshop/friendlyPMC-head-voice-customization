RELEASE NOTES (3.6.0):
 - removed looting bots dependencies, this also means you cannot use the loot corpse command anymore but you can now tell bots to pick up loot that is elivated (like on a table)
 - reserved secure container of bots for extra ammo. The secure container of a bot will be used for adding extra ammo for the main weapon. If you create presets that include a secure container, that will be ignored and instead use the default one the bot would spawn with.
 - changed "balance" tactic which is now named "default" where bots will look for shooting spots when at a distance from the enemy instead of falling back to holder tactic
 - fixed bots not appearing under the same group. Player will not apear as such as Raid Review Mod uses botsGroup id for determining thins
 - fixed BEAR still speaking English when englishBear flag is off
 - "Fire" command removed
 - "Stop" command removed
 - "Hold Position" command changed to be temporary hold when in combat or tell bots to wait when out of combat. This does not affect Marksman
 - "Stop" gesture now behaves just like "Hold Position" except its for followers within 15 meter radius.
